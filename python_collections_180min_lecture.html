03 · 14 min

Lists 1: the everyday collection, and how to read it

A list is Rover's sensor log or task queue. Create it with square brackets and separate items with commas.

parts = ["motor", "sensor", "wheel", "camera", "battery", "gripper"]
print(parts)
print(len(parts))
print(type(parts))
['motor', 'sensor', 'wheel', 'camera', 'battery', 'gripper'] 6 <class 'list'>

Ordered

Items have a fixed position. New items are added at the end.

Changeable

You can change, add and remove items after the list is created.

Allows duplicates

The same value may appear many times, each with its own index.

Items can be of any type, and types can be mixed. Sensor readings are usually numbers:

readings = [23.5, 24.1, 22.8, 24.1]      # duplicates are fine
profile = ["Rover", 3, True, 12.5]       # mixed types
from_tuple = list(("a", "b", "c"))       # list() builds a list from anything
print(readings)
print(profile)
print(from_tuple)
[23.5, 24.1, 22.8, 24.1] ['Rover', 3, True, 12.5] ['a', 'b', 'c']

Index and slice

Every item has an index. The first item is [0], not [1]. Negative numbers count from the end: [-1] is the last item. A slice [start:stop] gives a new list from start up to, but not including, stop.

parts = ["motor", "sensor", "wheel", "camera", "battery", "gripper"]
print(parts[0])
print(parts[-1])
print(parts[2:5])
print(parts[:3])
print(parts[-4:-1])
print("camera" in parts)
print(parts.index("wheel"))
motor gripper ['wheel', 'camera', 'battery'] ['motor', 'sensor', 'wheel'] ['wheel', 'camera', 'battery'] True 2

Bonus: strings are sequences too

Everything you just learned about index and slice works on text, because a string is a row of characters:

print(name[0], name[-1])

List comprehension: a loop in one line


Syntax: newlist = [expression for item in iterable if condition]. The if part is optional. Read it aloud: "give me expression for each item in the list, but only if condition".

Building a blank grid: another copy trap


To make a 2-row, 3-column grid of zeros, the obvious line [[0] * 3] * 2 is a trap. Predict what happens, then compare with the safe version:

Rover Mission Control: all four collections together


Time to combine everything. Rover lives on a 6 by 6 floor. It starts at (0, 0) facing North. It understands three commands: F (forward one cell), L (turn left) and R (turn right). Three obstacles block the way, and Rover simply refuses to drive into one.


Step 1: the data


Look at what each collection does here:


SIZE = 6
HEADINGS = ("N", "E", "S", "W")
MOVES = {"N": (0, 1), "E": (1, 0), "S": (0, -1), "W": (-1, 0)}
OBSTACLES = {(3, 2), (4, 4), (1, 4)}




      
tuple: HEADINGS
The compass never changes, so it is a tuple. Turning right means index + 1.

      
dict: MOVES
Look up a heading, get the (dx, dy) step. Values are tuples.

      
set: OBSTACLES
A set of (x, y) tuples. Is a cell blocked? cell in OBSTACLES answers fast.

    


Step 2: the brain, one function


def run_rover(commands):
    x, y = 0, 0                       # start in the corner, facing North
    heading = 0                       # index into HEADINGS
    path = [(x, y)]                   # list of tuples
    for cmd in commands:
        if cmd == "R":
            heading = (heading + 1) % 4
        elif cmd == "L":
            heading = (heading - 1) % 4
        elif cmd == "F":
            dx, dy = MOVES[HEADINGS[heading]]
            nxt = (x + dx, y + dy)
            inside = 0 <= nxt[0] < SIZE and 0 <= nxt[1] < SIZE
            if inside and nxt not in OBSTACLES:
                x, y = nxt
                path.append(nxt)
    return (x, y), HEADINGS[heading], path



How the turning works

      
heading is an index into HEADINGS. Turning right adds 1, turning left subtracts 1, and % 4 wraps around so that after "W" (index 3) comes "N" (index 0) again. Python's % keeps the result between 0 and 3 even for negative numbers, so (0 - 1) % 4 is 3.

E12 · Count blocked moves
challenge
Copy run_rover from Step 2 and change it so it also returns how many F commands were blocked. Test it with the commands below and print the final position and the blocked count.
(3, 1) 2
Hint
Add blocked = 0 before the loop, and an else: branch under the if inside and ... test. Remember the extra value in return.
Solution
SIZE = 6
HEADINGS = ("N", "E", "S", "W")
MOVES = {"N": (0, 1), "E": (1, 0), "S": (0, -1), "W": (-1, 0)}
OBSTACLES = {(3, 2), (4, 4), (1, 4)}

def run_rover(commands):
    x, y = 0, 0
    heading = 0
    path = [(x, y)]
    blocked = 0
    for cmd in commands:
        if cmd == "R":
            heading = (heading + 1) % 4
        elif cmd == "L":
            heading = (heading - 1) % 4
        elif cmd == "F":
            dx, dy = MOVES[HEADINGS[heading]]
            nxt = (x + dx, y + dy)
            inside = 0 <= nxt[0] < SIZE and 0 <= nxt[1] < SIZE
            if inside and nxt not in OBSTACLES:
                x, y = nxt
                path.append(nxt)
            else:
                blocked = blocked + 1
    return (x, y), HEADINGS[heading], path, blocked

pos, heading, path, blocked = run_rover(["R", "F", "F", "F", "L", "F", "F", "F"])
print(pos, blocked)
